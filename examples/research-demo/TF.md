## 1. 헌장 (G0에서 대표가 승인)

표에 빈칸 표시가 하나라도 남아 있으면 `tf.py`가 G0 승인을 막는다.

| 항목 | 내용 |
|---|---|
| 핵심 질문 (이 TF가 답할 한 문장) | 가상소재의 분리막 물량 회복이 2027년 이익을 시장 기대보다 끌어올리나? |
| 배경 (상황 → 문제) | 단가 하락으로 시장 기대가 낮아졌지만 고객사 증설 발표가 이어지고 있다 |
| 최종 의사결정자·독자 | 대표(개인 학습용 분석) / 독자: 대표 본인 |
| 성공 기준과 합격선 | 과거 숫자 100% 공시 대조, 시나리오 3개와 확률 표현, 논지가 깨지는 조건 명시 |
| 범위 / 제외 | 분리막 사업 / 제외: 다른 사업부, 단기 주가 예측 |
| 기준 시점 (자료·가격 기준일) | 2026-11-02 종가, 2025년 사업보고서 |
| 제약 (시간·도구·비용·비밀) | 3주, 공개 자료만, 투자 권유 아님 |
| 레드팀 관점 3개 (독자가 던질 질문) | ① 단가 하락이 더 깊으면? ② 증설이 늦어지면? ③ 이미 주가에 반영됐다면? |
| 이미 가진 자료·핵심 자료원 | 사업보고서(AI가 수집), 업계 리포트 요약(대표가 구함) |
