> AI는 수석 비서이자 노련한 파트너다. 운영 규칙은 `AGENTS.md`, 공통 규칙은 `blueprint/common.md`, 팀 방식은 `blueprint/consulting.md`.

## 1. 헌장 (G0에서 대표가 승인)

표에 빈칸 표시가 하나라도 남아 있으면 `tf.py`가 G0 승인을 막는다.

| 항목 | 내용 |
|---|---|
| 핵심 질문 (이 TF가 답할 한 문장) | 상위 거래처 이탈을 막아 내년 매출을 지키려면 무엇부터 해야 하나? |
| 배경 (상황 → 문제) | 거래처 수는 유지되지만 상위 거래처의 재주문 간격이 길어지고 있다 |
| 최종 의사결정자·독자 | 대표(영업 총괄) / 독자: 경영진 |
| 성공 기준과 합격선 | 실행안 3개 이내, 각 안에 대상 거래처·담당·기대 효과·확인 지표가 있다 |
| 범위 / 제외 | B2B 거래처 유지 / 제외: 신규 거래처 확보, 가격 정책 전면 개편 |
| 기준 시점 (자료·가격 기준일) | 2026-10-31까지의 사내 판매 데이터 |
| 제약 (시간·도구·비용·비밀) | 2주, 사내 판매 데이터만 사용, 외부 설문 없음 |
| 레드팀 관점 3개 (독자가 던질 질문) | ① 영업: 현장에서 돌아가나? ② 재무: 매출 효과는 얼마인가? ③ 경영진: 왜 지금인가? |
| 이미 가진 자료·핵심 자료원 | 거래처별 월 매출(대표가 전달), 업계 공개 통계 |

## 2. 기록 위치

- 할 일·관문·결정·리스크·자료 요청: `tf/state.json` (직접 고치지 않고 `python tf.py ...`로 고친다)
- 출처: `tf/sources.csv` (본문에서 `[S번호]`로 인용)
- 작업물: `work/drafts/` 초안 · `work/final/` 최종본 · `work/gates/` 관문 메모
