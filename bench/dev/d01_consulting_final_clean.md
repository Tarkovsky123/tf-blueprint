# 가상 인화지 유통사 — 거래처 유지 방안

## 1. 결론

상위 거래처 이탈을 막는 것이 신규 확보보다 먼저다. 상위 20% 거래처가 매출의 64%를 낸다 [S1].
근거는 3가지다: 매출 집중, 재주문 주기, 경쟁사 가격.

## 2. 근거

### 2.1 매출 집중

2025년 기준 거래처는 412곳이고, 그중 상위 82곳이 매출의 64%를 차지한다. [S1]
거래처당 평균 매출은 1.9억 원이다 [계산: work/calc.py].

| 구분 | 거래처 수 | 매출 비중 |
|---|---|---|
| 상위 | 82곳 | 64% |
| 나머지 | 330곳 | 36% |

출처: [S1]

### 2.2 재주문 주기

재주문 간격이 45일을 넘으면 이탈 위험군으로 본다 [가정].

```python
share = 82 / 412  # 19.9%
```

## 3. 실행 계획

1. 11/4까지 G2 스토리라인 확정

3. 2단계로 나눠 확산한다.

## 4. 리스크와 한계
